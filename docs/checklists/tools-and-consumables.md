# Tools & consumables

Have these on hand before assembly day.

## Tools

- [ ] Precision Phillips screwdriver set (PH00 / PH000)
- [ ] Plastic spudger / pry tool (FPC connectors, prying shells)
- [ ] ESD wrist strap + mat
- [ ] Tweezers (fine)
- [ ] Flush cutters (optional, cable management)
- [ ] Multimeter (continuity / battery voltage check)
- [ ] Magnifier or headband loupe (u.FL seating)

## Consumables

- [ ] Thermal pad for the CM4 (check thickness against the shell clearance)
- [ ] Isopropyl alcohol (99%) + lint-free wipes
- [ ] Kapton tape (insulating, cable tacking)
- [ ] Spare u.FL pigtails (optional)

## Host / first-boot gear

- [ ] microSD card, 32 GB+ (first boot / recovery)
- [ ] microSD card reader on the imaging PC
- [ ] Known-good USB-C data cable (for `rpiboot` eMMC/NVMe flashing — must be a data cable, not charge-only)
- [ ] Imaging PC with Raspberry Pi Imager or `dd`
- [ ] USB-C power supply

## Notes

- The `rpiboot` flashing step fails silently on charge-only USB-C cables. Verify the cable carries data first.
