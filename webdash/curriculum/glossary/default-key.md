---
id: default-key
term: Default key (PSK)
tooltip: A channel's pre-shared key. The default key AQ== is published, so the default channel is effectively public.
good_bad: 'Fancy''s SCMesh primary uses it: anyone on SCMesh can read what Fancy sends.'
try_this: Never put location or anything private in a message.
learn_more: '#/learn/m/M4'
---

Changing the key cuts you off from nodes that use the default one.
